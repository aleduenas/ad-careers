# infra/docker/.env.example

**Authority:** [infra/docker/.env.example](../../../infra/docker/.env.example).

Provides the non-secret database environment template.

## Inputs

When configuring manually, copy these settings into root `.env` and replace the placeholder password. `node src/helpers/db-infra.mjs init` instead generates a random password and default port directly, refusing to overwrite an existing file.

## Outputs and behavior

Defines password and host port only. The real `.env` is private and must stay untracked.

## Dependencies and callers

Reference for manual setup; `db-infra.mjs init` does not parse this file. Compose consumes the real environment values. Node/Go clients also allow `DATABASE_URL` as documented in the database guide.
