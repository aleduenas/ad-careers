# src/cvgen/test-drafting-integration.mjs

**Authority:** [src/cvgen/test-drafting-integration.mjs](../../../src/cvgen/test-drafting-integration.mjs).

Runs actual intake, status, CV drafting, cover-letter drafting and publishing launchers against a unique schema in a career_ops_test_* database. The CV and the letter are separate launcher runs: it verifies `draft-cv.mjs` rejects `--cover-letter`, writes no letter and never shows the worker the letter samples, and that `draft-cover-letter.mjs` then makes exactly one generation call with its own prompt (no CV worksheet) before the letter is published. Synthetic CLI output first returns an invalid summary, then verifies exactly one fresh repair call succeeds. It exercises path-specific and section-isolated repair evidence, auditable source/rendered repair prompts, a validation repair that returns only the fixed block and is merged into the previous answer with every other section unchanged, the compact CV sent once, literal prompt substitution (including placeholder-looking input), complete multi-paragraph customization context and real Chromium rendering. It also verifies previews do not write, duplicate intake fails, canonical company spelling is preserved, JD revision remains one, manual status survives late evaluation, and output includes the permanent job ID. Cleans fixture schema/tree and retains rendered evidence under logs/tests/drafting-integration/rendered. Requires TEST_DATABASE_URL; skips without it.

Run: `node src/helpers/db-test.mjs`. Assertions fail with a nonzero exit code. Discovered by `src/test-all.mjs`; database/Chromium prerequisites are described above.
