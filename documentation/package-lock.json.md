# Node dependency lock

**Authority:** [package-lock.json](../package-lock.json).

Records the resolved npm dependency tree and integrity metadata associated with `package.json`, including the exact browser dashboard, Fastify and schema-to-TypeScript toolchain. Startup adds a root script only, so this dependency lock remains unchanged. `npm ci` uses this lock in CI; update it through npm when dependencies change. There is one root lockfile, with no nested web lock. No user data or runtime credentials belong here.
